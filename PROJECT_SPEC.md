## Overview
Dementia assistance and cognitive support application designed to provide memory aids, routines, and voice interactions for patients and caregivers.

## Key Decisions & Constraints
- **Frontend**: React + Vite + Tailwind CSS v4
- **Hosting**: GitHub Pages (`https://vickyxcodes.github.io/dementia/`)
- **Database / Backend**: Firebase & Firestore
- **Voice / Speech**: Web Speech API (MVP)
- **Language**: English first, additional languages in future phases
